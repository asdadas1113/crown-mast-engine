# 후속 연구 자리표시자

이 디렉터리는 1연구 결과에서 정밀 검증할 현상이 확정되기 전까지 사용하는 **구조 예시용 자리표시자**다.

후속 연구 주제가 확정되면 이 디렉터리를 그대로 결과 저장소로 쓰지 않고, 다음과 같이 주제를 드러내는 새 디렉터리를 만든다.

```text
02_main_damage_structure/
03_crown_mast_growth_sensitivity/
04_hit_spread_sensitivity/
```

위 이름은 예시일 뿐이며 실제 연구 번호와 주제는 1연구 결과를 보고 확정한다.

각 후속 연구도 반드시 다음 세 영역을 독립적으로 가진다.

```text
<후속연구>/
├─ human/
├─ machine/
└─ validation/
```

## 역할

후속 연구는 1연구에서 발견된 독특한 결과나 설명되지 않는 패턴을 대상으로 한다.

예시:

- 비슷한 Main 딜 지분인데 정책 반응이 크게 다른 캐릭터
- 특정 성장 조건에서만 winner가 뒤집히는 캐릭터
- Crown/Mast 상대 성장에 민감한 roster
- DEF/core/우월에 따라 결과가 뒤집히는 roster
- 특정 딜 source나 스킬 구조와 연관된 것으로 보이는 이상치

후속 연구는 필요에 따라 1연구보다 좁은 캐릭터 표본을 사용하되, 성장공간이나 기전 분석은 더 촘촘하게 설계한다.

현재는 후속 연구 실행이나 구체 설계를 시작하지 않는다.
