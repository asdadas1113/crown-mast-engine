# 1연구 최종 실행 전 검증 — 2026-09-06

## 1. 목적

Crown–Mast 1연구의 공식 28,188 scenario 전투 batch를 실행하기 전에 다음을 최종 확인한다.

- 기존 numerical regression의 원인 분류
- Moran Favorite Item / Scarlet: Black Shadow / Liberalio model gate 종료 여부
- actor/reload 변경 후 전체 회귀 무결성
- 87 roster × 27 growth × 12 environment case generator 무결성
- 공식 전투 시뮬레이션이 실행되지 않았는지 여부

이 검증은 **공식 연구 실행이 아니다.**

## 2. numerical regression 분류

기존 총딜 baseline 실패 3건은 Python 3.11과 3.12 사이의 초미세 부동소수점 누적 차이로 확인했다.

- 20억대 총딜에서 약 `0.00005~0.00011` 수준
- 기대 총딜 값은 변경하지 않음
- 절대 총딜 허용오차를 `1e-3`으로 정상화

연구 결론이나 모델 수치를 맞추기 위한 기대값 재작성은 하지 않았다.

## 3. actor model gate 종료

### Moran Favorite Item

### Scarlet: Black Shadow

직접 계측값과 공용 reload 공식에 맞춰 reload body와 fixed delay를 분해했다.

```text
raw reload body = 120f = 2.0s
fixed reload-start delay = 12f = 0.2s
effective reload at 0% reload speed = 142f ≈ 2.3667s
attack cycle = 18f charge + 26f recovery = 44f ≈ 0.7333s
```

대표 재분석:

```text

relative     ≈ -0.3081%
```

Conventional 우세 방향은 유지됐다.

### Liberalio

reload body와 고정 reload-start delay를 분리했다.

```text

fixed reload-start delay = 12f = 0.2s
```

## 4. 첫 final preflight에서 발견된 stale tests

GitHub Actions run `33998906485`에서 focused 단계는 성공했으나 full regression에서 7개 테스트가 실패했다.

분류 결과 모두 엔진 회귀가 아니라 현행 API/분류/reload 모델을 따라오지 못한 기존 테스트 기대값이었다.

- `RotationWinner.EQUAL` → `RotationWinner.TIE`
- 폐기된 `NO_SCALING_BREAK_EVEN` 기대 → 현행 dominance 분류
- 폐기된 `SCALING_BREAK_EVEN_ONLY` 기대 → 현행 `STANDARD_BREAK_EVEN` + share unavailable
- 역방향 crossing → 현행 `REVERSE_BREAK_EVEN`
- dominance case break-even accessor 기대 동작 정렬
- SBS `reload_frames=152` 단일값 기대 → `120f body + 12f fixed delay`

엔진 동작을 테스트에 맞춰 바꾸지 않았다. 테스트를 현행 의미에 맞춰 정리했다.

## 6. 결론

1연구의 **모델·회귀·case generator 실행 전 gate는 모두 닫혔다.**

현재 상태:

```text
execution model gates = 0
execution_ready = true
status = design-frozen-execution-unapproved
```

단, 사용자 명시 승인은 아직 없다.

이번 검증에서 28,188개의 case 객체를 생성해 조건과 ID를 검사했지만 **28,188개의 전투 시뮬레이션은 실행하지 않았다.** 공식 run ID, 실제 manifest, raw/aggregate 결과도 생성하지 않았다.

다음 단계는 사용자가 공식 1연구 실행을 명시적으로 승인하는 경우에만 시작한다.
