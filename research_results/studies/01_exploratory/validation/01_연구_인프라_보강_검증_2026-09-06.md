## 3. 보강 항목

### 3.1 캐릭터 데이터 재현성

문제:
- 스킬 수치를 임시 변경해도 기존 catalog revision과 동일하게 취급될 수 있었다.
- 저장된 scenario만으로 실제 사용한 캐릭터 데이터가 동일했는지 확인하기 어려웠다.

보강:
- 로드된 표준 캐릭터 catalog 전체 내용에 SHA-256 content hash를 부여한다.
- `with_skill_value()`로 스킬 수치를 바꾼 경우 변경 actor·skill·field·value를 catalog revision에 기록한다.
- 저장 scenario의 예상 catalog revision과 runtime catalog revision이 다르면 실행을 거부한다.

검증:
- 같은 override는 같은 revision을 생성한다.
- 표준 catalog와 override catalog는 다른 revision을 가진다.
- 표준 scenario로 override catalog를 실행하면 revision mismatch로 fail-closed 된다.

### 3.2 전투 숫자 finite 검증

문제:
- `NaN` 또는 무한대가 일부 숫자 조건을 통과할 수 있었다.

보강:
- boss DEF, core hit rate, range bonus, element multiplier, Full Burst bonus, boss damage taken, duration 등 주요 실수 입력에 finite 검증을 추가했다.
- interface 숫자 파싱 경로에서도 비유한 값을 거부한다.

검증:
- `boss_def=NaN`
- `boss_def=+inf`
- `duration_sec=NaN`

위 입력이 모두 fail-closed 되는 것을 확인했다.

### 3.3 버스트 시간축 overlap 검증

문제:
- 개별 cycle 내부 순서는 검증했지만, 이전 Full Burst가 끝나기 전에 다음 cycle의 B1이 시작하는 timeline을 막지 못했다.

보강:
- `ResearchScenario` 경로와 직접 engine simulation 경로 모두에서 인접 cycle overlap을 거부한다.

검증:
- cycle 1 Full Burst 종료 이전에 cycle 2 B1이 시작하는 인위적 timeline이 양쪽 경로에서 모두 거부되는 것을 확인했다.

현재 RAID14 표준 timeline은 overlap 조건을 밟지 않는다.

### 3.4 UI 초기화 상태 오염

문제:
- UI에서 overload 공격력 줄 수 등을 변경한 뒤 초기화하면, 화면에 남은 값이 다시 state에 저장될 수 있었다.

보강:
- 기본값 초기화 시 기존 build row를 제거한 뒤 다시 렌더링하도록 순서를 변경했다.

검증:
- reset 로직에서 `state.builds.clear()` 이후 기존 row 제거가 `syncB3Options()`보다 먼저 실행되는 것을 regression으로 고정했다.

### 3.5 Windows CP949 시작 로그

문제:
- 시작 로그의 en dash 문자가 CP949 stdout에서 encode되지 않아 서버가 종료될 수 있었다.

보강:
- 시작 로그를 ASCII 하이픈 기반 문자열로 변경했다.

검증:
- CP949 `TextIOWrapper` 환경에서 시작 로그 출력이 성공함을 확인했다.

### 3.6 html2canvas 패키징 및 package discovery

문제:
- PNG 내보내기에 필요한 `web/vendor/html2canvas.min.js`와 라이선스가 wheel package-data에 포함되지 않았다.
- 추가 검증 과정에서 setuptools가 repo의 `archive/`, `research_results/`, `crown_mast_engine/`를 여러 top-level package로 오인해 wheel build 자체가 실패하는 문제도 확인됐다.

보강:
- `web/vendor/*.js`, `web/vendor/*.txt`를 package-data에 포함했다.
- setuptools package discovery 대상을 `crown_mast_engine*`으로 제한했다.

검증:
- wheel build 성공
- `crown_mast_engine/web/vendor/html2canvas.min.js` 포함 확인
- `crown_mast_engine/web/vendor/html2canvas.LICENSE.txt` 포함 확인
- `archive/` 및 `research_results/`가 wheel에 잘못 포함되지 않음을 확인
