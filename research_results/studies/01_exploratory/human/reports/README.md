# 1연구 실행별 사람용 보고서

공식 실행마다 기계 데이터의 `run_id`와 동일한 폴더를 만든다.

```text
reports/<run_id>/
├─ 00_전체_요약.md
├─ 01_세컨더리_기준점_분석.md
├─ 02_메인_B3_분석.md
├─ 03_B1_분석.md
├─ 04_효과크기_분석.md
├─ 05_역전_구조_분석.md
├─ 06_성장_및_환경_민감도.md
├─ 07_해석과_한계.md
├─ 08_후속_연구_후보.md
└─ cases/
```

보고서는 같은 run의 `machine/runs/<run_id>/manifest.json`, aggregate 및 validation 기록을 근거로 작성한다. 재실행 결과는 기존 보고서를 덮어쓰지 않는다.
