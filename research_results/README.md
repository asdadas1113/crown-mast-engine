## 새 연구 1의 역할

새 연구 1은 보편적인 단일 임계값이나 최적 운용 규칙을 확정하는 것이 아니라, **유의미한 변수와 상호작용을 탐색하고 후속 연구 후보를 고르는 단계**다.

주요 탐색 후보:

- Main B3 identity
- Secondary B3 identity
- 성장 격차
- core 조건
- 우월 조건
- boss DEF
- 위 변수들의 상호작용

결과가 반복적으로 튀는 캐릭터/조건은 anomaly candidate로 표시하되, 엔진 재검증과 복수 환경에서 재현되기 전에는 기전 설명을 확정하지 않는다.

## 현재 runs 영역

```text
runs/
```

`runs/`는 앞으로 승인된 새 연구 실행만 저장한다. 기존 study v1 run과 당시 template은 archive로 이동했다.

새 연구 설계가 아직 동결되지 않았으므로 과거 run schema를 현행 표준으로 간주하지 않는다.
