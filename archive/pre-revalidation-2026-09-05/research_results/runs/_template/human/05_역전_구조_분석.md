# 역전 구조 분석

Conventional과 Funnel의 우열이 어떤 조건 변화에서 뒤집히는지 paired case 중심으로 분석한다.

포함 항목:
- 같은 roster에서 성장조건만 바뀐 역전
- Main 우월 off/on 역전
- 코어 off/on 역전
- Secondary 성장 변화에 따른 역전
- Main `g` 증가와 rest opportunity loss 감소 중 어느 쪽이 역전을 설명하는지
- 역전 부근의 Conventional Secondary 딜 지분

가능하면 한 변수만 달라지는 matched pair를 우선 사용한다.
