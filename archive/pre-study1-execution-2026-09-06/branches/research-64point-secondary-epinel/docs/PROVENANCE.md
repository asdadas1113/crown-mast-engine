# Import provenance

This directory was imported from the 2026-09-01 Crown–Mast research engine archive.

Kept:
- executable engine source
- regression tests
- local web UI and bundled html2canvas license
- character catalog data required by the engine
- latest v6 research handoff note
- overload formula cross-validation note

Excluded from Git:
- Python bytecode/cache directories
- old v4/v5 handoff drafts superseded by v6
- screenshots and generated comparison/checkpoint outputs
- anonymous BlaBlaLink/profile JSON dumps and helper archive
- chat screenshots, Word working documents, and temporary implementation memos

The excluded files are not required to run the engine or reproduce its current regression suite. Profile/account-derived JSON is intentionally kept out of version control.
