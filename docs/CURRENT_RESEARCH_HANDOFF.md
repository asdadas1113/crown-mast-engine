```text
docs/CURRENT_RESEARCH_HANDOFF_2026-09-05.md
```

새 작업을 시작할 때는 이 파일보다 날짜가 붙은 최신 인계문서를 먼저 읽고, GitHub에서 `research/14-burst-baseline`의 최신 HEAD를 다시 확인한다.

## 중요 상태

기존 공식 연구 1 `crown-mast-secondary-opportunity-v1`의 29,952 scenario 결과는 **폐기 / superseded** 상태다. 새 연구 1의 결론이나 사전 기대값으로 참고하지 않는다.

Canonical status:

```text
research_results/RESEARCH_STATUS_2026-09-05.md
research_results/runs/official-complete-2026-09-05/SUPERSEDED_DO_NOT_USE.md
```

신데렐라는 기존 결과를 승계하는 예외가 아니라 **재검증 우선 감시 대상**일 뿐이다. 엔진 재검증과 방어력 축을 포함한 새 연구에서도 유독 튀는 결과가 독립적으로 재현될 경우에만 후속 기전 연구로 넘긴다.

`main`은 사용자 명시 지시 없이는 수정하거나 병합하지 않는다. 새 공식 연구 batch도 엔진 재검증과 설계 재동결 이후 사용자 명시 승인 전에는 실행하지 않는다.
