# RAID14 initial recalculation (2026-09-01)

This note records the first calculation pass after introducing the practical 14-burst timeline.
It is a regression/research note, not a universal gameplay claim.

## Scope

- battle duration: 180 s
- timeline: `RAID14_TIMELINE`
- 14 burst cycles, 12.70 s B1-to-B1 interval
- c14 terminal B2: 2-stack Mast in both compared policies
- default comparison roster: Liter / Crown / Mast: Romantic Maid / Rapi: Red Hood / Helm (Favorite Item)
- default catalog/build/combat settings from the current engine
- external boss-pattern losses remain OFF

The legacy 12-burst `ResearchScenario.standard()` remains untouched and is used only as a regression reference.

## Opening B2 influence window

The opening comparison is not clipped at the first Full Burst end.
`analyze_first_burst_entry_choice()` / `analyze_entry_variants()` measure from the first B1 until the two opening variants' active buff states converge.

For `RAID14_TIMELINE`:

```text
first B1                       2.20 s
first B2                       2.26 s
first Full Burst start         2.32 s
first Full Burst end          12.32 s
first Crown Burst end         17.26 s
opening buff-state convergence 17.32 s
```

The final 0.06 s beyond Crown Burst expiry comes from Crown S1's Burst-caster-specific caster-ATK window beginning at Full Burst entry rather than B2 activation.
Therefore a 10-second first-Full-Burst-only measurement would undercount the Crown opener's downstream influence.

## Default roster: opening result

Within the full opening influence window:

```text
Crown opener damage   226,495,936.70
Mast M1 opener damage 230,370,884.03
Mast - Crown            3,874,947.33
relative change              +1.7108%
```

In the current default case, M1 opener is therefore stronger over the complete opening influence window.
The same absolute opening delta is preserved whether the later policy is conventional or sustained funnel; the opener comparison does not leak into the later rotation comparison.

## Legacy 12-burst vs practical 14-burst

Crown opener, default roster:

| Metric | Legacy 12 burst | RAID14 |
|---|---:|---:|
| Conventional total | 2,144,196,385.51 | 2,793,708,977.32 |
| Funnel total | 2,118,326,068.35 | 2,744,001,195.39 |
| Funnel relative change | -1.2065% | -1.7793% |
| Conventional main share | 46.4652% | 40.0096% |
| Break-even main share | 70.6844% | 66.3750% |

The winner does not change in this baseline: conventional `C,C,M` remains ahead.
However, the faster/longer 14-burst decision horizon materially changes the local break-even value, so the old 12-burst threshold should not be carried forward as the new research result.

Mast opener, RAID14:

```text
Conventional total        2,797,583,924.65
Funnel total              2,747,876,142.72
Funnel relative change           -1.7768%
Conventional main share          40.0759%
Break-even main share            66.4366%
```

The opener shifts both later-policy totals by the same absolute amount, leaving the conventional-vs-funnel delta unchanged at approximately -49.71 million in this case.

## Terminal-cycle propagation

Direct B2 choices are identical at c13 and c14 for both policies:

```text
c13 Crown
c14 Mast at Drunken 2
```

Even so, c13 retains a small propagated difference from earlier state:

```text
c13 funnel - conventional  +105,297.77  (+0.0656%)
c14 funnel - conventional         0.00
```

This is the intended behavior: c13 can still carry state produced by c11/c12, while c14 has converged in the current default case. The terminal extension therefore reduces the artificial effect of ending the decision horizon immediately after c12 without introducing a new direct B2 mismatch.

## B1 opener spot-check

To check whether the M1 opener result was specific to Liter, the same Rapi/Helm B3 pair was recalculated with the currently implemented standard builds for four supported B1 characters.
These are engine cases, not population-wide claims.

| B1 | M1 opener vs Crown opener | Conventional vs funnel | Break-even main share |
|---|---:|---:|---:|
| Liter | +1.7108% | -1.7793% | 66.3750% |
| Anis: Star | +3.9266% | -1.6916% | 60.1501% |
| Moran (Favorite Item) | +2.2963% | -1.6067% | 58.8831% |
| Little Mermaid | +2.8267% | -2.0205% | 65.6210% |

All four current spot-checks favor the M1 opener, while conventional `C,C,M` remains ahead of sustained funnel at the tested main-damage shares.
More B3/build cases are still required before treating either tendency as universal.

## Verification

A dedicated `tests/test_raid14_research.py` regression file checks:

- opening window extends to 17.32 s rather than the first Full Burst end
- default M1 opener advantage
- opening delta is independent of the later conventional/funnel choice
- moving from the legacy timeline to RAID14 changes the break-even value without changing the baseline winner

The targeted RAID14/research regression set and Python `compileall` passed locally. A full all-module suite is computationally slow and exceeded the single-run execution limit during this pass; previously existing 12-burst reference assertions used in the targeted set remained unchanged and passed.
